## 📌 1. Introduction & Objectives

Computer technology mein **Input** aur **Output** devices bahut important hain. Ye human aur machine ke beech communication ka bridge banate hain.
*   **Input Devices:** Ye data aur commands computer mein feed karte hain (jaise keyboard, mouse).
*   **Output Devices:** Ye processed information ko user ko present karte hain (jaise monitor, printer).

Ye devices human-computer interaction (HCI) ka core hain. Inki advancement ne user experience ko bahut behtar banaya hai aur productivity ko badhaya hai.

**Objectives:**
*   Input aur output devices ka concept samajhna.
*   Alag-alag types ke input devices mein differentiate karna.
*   Input devices ko use karne mein proficiency demonstrate karna.

## ⌨️ 2. Input Devices

Input devices wo hardware components hain jo users ko computer system ke saath interact karne dete hain. Ye text, images, ya commands input kar sakte hain. Main types hain: Keyboards, Pointing Devices, Scanning Devices, OCR, aur Biometric Input Devices.

### 2.1 Keyboards

Keyboard ek common input device hai jo users ko text, numbers, aur commands enter karne deta hai. Ye personal aur professional dono environments mein data entry ke liye essential hai.

**Working Nature:**
*   Keyboard mein keys hoti hain, har key ek specific character ya function represent karti hai.
*   Jab key press hoti hai, toh wo computer ko electrical signal bhejti hai, jo input ko process karke screen par corresponding character display karta hai.

**Properties:**
*   **QWERTY layout** sabse common hai.
*   Keys mein letters, numbers, symbols, aur function keys ho sakti hain.
*   Kuch keyboards mein multimedia keys ya backlighting jaise additional features hote hain.

**Characteristics:**
*   Tactile (touch) aur visual feedback deta hai.
*   Text-based input ke liye suitable.
*   Wired ya wireless ho sakta hai.

**Examples:** Standard computer keyboard, laptop keyboard, gaming keyboard.

**Advantages:**
*   Familiar aur widely used.
*   Typing tasks ke liye suitable.
*   Functions aur shortcuts ka quick access.

**Disadvantages:**
*   Typing-related strain ya injuries ho sakti hain.
*   Precise pointing ya drawing wale tasks ke liye limited.

---

### 2.2 Pointing Devices

Pointing devices wo input peripherals hain jo computer screen par cursor ya pointer ki movement ko control karte hain. Ye users ko Graphical User Interfaces (GUIs) ke saath interact karne, software navigate karne, aur objects manipulate karne dete hain.

**Working Nature:**
*   Ye screen par cursor move karte hain aur GUIs ke saath interact karte hain.
*   Inme physical movement ya gestures involve hote hain.

**Properties:**
*   Common types: Mice, touchpads, trackballs, aur touchscreens.
*   Movement detect karne ke liye optical ya laser sensors use hote hain.

**Characteristics:**
*   **Cursor Control:** Precise control over cursor position (clicking, dragging, selecting).
*   **Navigation:** GUIs, menus, aur web pages navigate karna.
*   **Gestures:** Kuch devices gesture-based interactions support karte hain (zooming, scrolling, rotating).
*   **Buttons:** Clicking, double-clicking, right-clicking ke liye buttons.
*   **Scroll Wheels:** Vertical aur horizontal scrolling ke liye.

**Examples:**
*   **Computer Mouse:** Sabse common. Do buttons aur ek scroll wheel. Flat surface par move karke cursor control karte hain.
*   **Laptop Touchpad:** Laptops mein built-in. Finger movements se cursor control aur gestures.
*   **Trackball:** Cursor move karne ke liye ball rotate karte hain. Precise tasks ke liye suitable.
*   **Graphics Tablet:** Graphic designers ke liye. Stylus aur tablet surface se precise drawing aur handwriting input.
*   **Touchscreen:** Smartphones, tablets, aur kuch computers mein. Screen par tap ya swipe karke direct interaction.

**Advantages:**
*   **Precision:** Accurate tasks ke liye ideal.
*   **Versatility:** Office work se gaming tak various applications.
*   **Ease of Use:** Generally easy to use, no special skills required.
*   **Gesture Support:** Enhanced user interactions.

**Disadvantages:**
*   **Space Requirement:** Flat aur clean surface ki zaroorat.
*   **Learning Curve:** Advanced features wale devices mein learning curve.
*   **Maintenance:** Mechanical devices (jaise mice) ko periodic cleaning chahiye.

### 2.3 Scanning Devices

Scanning devices wo hardware peripherals hain jo physical documents, images, ya objects ko digital format mein convert karte hain. Ye digitization, storage, aur manipulation ke liye crucial hain.

**Working Principles:**
*   **Optical Sensors:** Scanners optical sensors (CCDs ya CIS) use karte hain images capture karne ke liye. Ye light aur color variations detect karke content ko digitally represent karte hain.
*   **Resolution:** Scanners ki resolution **DPI (dots per inch)** mein measure hoti hai. Higher DPI = sharper aur more detailed scans.
*   **Colour Depth:** Scanners grayscale ya colour mein images capture kar sakte hain. Colour depth batati hai kitne colours ya shades reproduce ho sakte hain (e.g., 24-bit = millions of colours, 8-bit = 256 colours).
*   **Scanning Modes:** Flatbed scanning, sheet-fed scanning, aur handheld scanning.

**Types of Scanning Devices:**
1.  **Flatbed Scanners:** Sabse common, photocopier jaisa. Glass bed par document ya photo rakhte hain scanning ke liye.
2.  **Sheet-fed Scanners:** Multiple pages quickly scan karne ke liye. Paper ki stacks handle karte hain aur automatically pages feed karte hain.
3.  **Handheld Scanners:** Portable, haath se document par move karte hain. Irregularly shaped objects ya large documents scan kar sakte hain.
4.  **Drum Scanners:** Rotating drum use karte hain. Extremely high resolution, professional graphic design aur printing mein use.
5.  **3D Scanners:** Objects ki shape aur dimensions 3D mein capture karte hain, 3D models banate hain.
6.  **Barcode Scanners:** Products, packages, ya labels par barcodes read karne ke liye specialized.

**Applications:**
1.  **Document Digitization:** Paper documents ko digital format mein convert karna (offices ke liye essential).
2.  **Image and Photo Scanning:** Photographers aur artists photos, artwork, negatives digitize karte hain.
3.  **OCR:** Scanners + OCR software printed text ko editable aur searchable digital text mein convert karte hain.
4.  **Barcode Scanning:** Retail aur logistics mein inventory management aur tracking.
5.  **Medical Imaging:** CT aur MRI scanners body ki detailed images banate hain.
6.  **3D Scanning:** Manufacturing, engineering, aur archaeology mein design aur analysis ke liye.

**Advantages:**
*   Physical documents aur images preserve aur archive karta hai.
*   Document sharing, editing, aur searching facilitate karta hai.
*   OCR ke through searchability enhance karta hai.
*   High-resolution scanning support karta hai.

**Disadvantages:**
*   Hardware maintenance required.
*   Kuch documents accurately scan nahi ho sakte, manual corrections chahiye.
*   Specialized scanners expensive hote hain.

### 2.4 OCR (Optical Character Recognition)

OCR ek technology hai jo printed ya handwritten text ko machine-readable text mein convert karti hai. Ye scanned images ya documents analyze karke characters recognize karti hai, jisse text editable, searchable, aur digital applications ke liye suitable ho jata hai.

**Working Principle (Steps):**
1.  **Scanning:** Physical document (paper ya handwritten note) scan hota hai. Scanner document ki image capture karta hai, jisme saare text characters hote hain.
2.  **Image Preprocessing:** OCR se pehle scanned image preprocess hoti hai (noise reduction, image enhancement, layout analysis) taaki quality improve ho aur text isolate ho.
3.  **Character Recognition:** OCR software complex algorithms aur pattern recognition techniques use karta hai characters ki shapes, patterns, structures analyze karne ke liye. Individual letters, numbers, punctuation, symbols identify karta hai.
4.  **Text Extraction:** Characters recognize hone ke baad, OCR software unhe machine-readable text mein convert karta hai. Ye text edit, search, ya digitally process ho sakta hai.
5.  **Post-processing:** Kabhi-kabhi errors correct karne aur accuracy improve karne ke liye post-processing steps apply hote hain (spell-checking, context analysis, formatting adjustments).
6.  **Output:** Final output digitised text hota hai, jo various formats (plain text, Word, PDF) mein save ho sakta hai.

**Properties:**
*   **Software-Based:** OCR typically software applications ya libraries hoti hain. Online OCR services bhi available hain.
*   **Language Support:** Modern OCR multiple languages aur fonts support karte hain.
*   **Accuracy:** Scanned image quality, font type, aur language par depend karti hai. Advanced systems high accuracy achieve karte hain.
*   **Handwriting Recognition:** Primarily printed text ke liye, par kuch software handwritten characters bhi recognize kar sakte hain (accuracy lower hoti hai).

**Examples of OCR Software:**
*   **ABBYY FineReader:** Accuracy aur language support ke liye popular.
*   **Adobe Acrobat OCR:** PDF documents mein text recognition.
*   **Tesseract:** Google ka open-source OCR engine.
*   **Readiris:** Document scanning aur conversion tasks ke liye.

**Advantages:**
*   **Text Digitization:** Printed/handwritten text ko editable, searchable digital text mein convert karta hai, manual data entry ki zaroorat nahi.
*   **Enhanced Accessibility:** Visually impaired logon ke liye printed materials accessible banata hai (text to speech ya Braille).
*   **Efficient Data Retrieval:** Digitized text easily searchable hota hai.

**Disadvantages:**
*   **Accuracy Variability:** Document quality, font, aur language par depend karti hai. Handwriting recognition less accurate.
*   **Formatting Challenges:** Original document ka formatting preserve nahi ho pata (especially complex layouts).
*   **Resource Intensive:** Computationally intensive, especially large documents ke liye.

### 2.5 Biometric Input Devices

Biometric input devices wo peripherals hain jo individuals ki unique physiological ya behavioural characteristics use karke unki identity verify karte hain. Ye biometric data capture karte hain, analyze karte hain, aur stored templates se compare karke access grant ya deny karte hain.

**Working Nature:**
1.  **Data Capture:** Biometric devices user se specific biometric data capture karte hain (fingerprints, facial features, iris patterns, palm prints, voice patterns, behavioural traits jaise typing rhythm ya signature dynamics).
2.  **Data Processing:** Captured data ko device ka internal software/hardware process karta hai aur unique digital template ya signature banata hai. Ye template securely store hota hai.
3.  **Authentication:** Jab user access karna chahta hai, unhe biometric data provide karna padta hai, jo device phir capture karta hai. Naya data stored template se compare hota hai identity verify karne ke liye.
4.  **Access Decision:** Comparison ke basis par device access grant ya deny karta hai. Agar data acceptable margin ke andar match hota hai, toh access granted; warna denied.

**Properties:**
*   **Uniqueness:** Biometric traits highly unique hote hain (identical twins bhi distinct hote hain).
*   **Security:** High level of security, impostors ke liye replicate karna difficult.
*   **Convenience:** Quick authentication, passwords ya physical tokens ki zaroorat nahi.
*   **Types of Biometric Data:** Fingerprints, facial features, iris patterns, palm prints, voice patterns, behavioural traits.
*   **Enrolment:** Users ko initially biometric system mein enrol karna padta hai (data capture aur reference template store).

**Examples:**
1.  **Fingerprint Scanners:** Fingertip ke unique ridge aur valley patterns capture aur analyze karte hain.
2.  **Facial Recognition Cameras:** Cameras aur algorithms se facial features ke basis par individuals identify karte hain.
3.  **Iris Scanners:** Eye ke coloured part (iris) ke unique patterns scan karke identity verify karte hain.
4.  **Voice Recognition Systems:** Person ki voice ki distinctive characteristics (pitch, tone, speech patterns) analyze karte hain.
5.  **Palm Print Scanners:** Palm ke unique patterns (creases aur lines) capture aur analyze karte hain.

**Advantages:**
*   **High Security:** Forge karna difficult, security enhanced.
*   **Convenience:** Passwords ya tokens ki zaroorat nahi.
*   **Speed:** Authentication quick aur almost instantaneous.

**Disadvantages:**
*   **Privacy Concerns:** Biometric data store karna privacy concerns raise karta hai. Secure storage crucial.
*   **Cost:** Biometric devices expensive ho sakte hain.
*   **False Acceptance/Rejection:** Systems kabhi-kabhi false positives (unauthorized users accept) ya false negatives (authorized users deny) produce kar sakte hain.

## 🖥️ 3. Output Devices

Output devices wo hardware components hain jo computer ko information aur data users ya other systems tak communicate karne dete hain. Ye CPU-generated digital data ko human-readable ya perceivable format mein convert karte hain. Main types hain: Monitors, Printers & Projectors, Speakers & Audio Output, aur Headsets & Earphones.

### 3.1 Monitors

Monitors essential output devices hain jo computer ke CPU se generated visual information display karte hain. Inhe screens ya displays bhi kehte hain, aur ye digital data aur applications ke saath interact karne ke liye user-friendly interface provide karte hain.

**Display Technologies:**
*   **LCD (Liquid Crystal Display):** Liquid crystal cells se light ka passage control karte hain, precise colour aur image representation.
*   **LED (Light Emitting Diode):** LCD panels ke backlight sources ke liye LEDs use karte hain, energy efficiency aur colour vibrancy.
*   **OLED (Organic Light Emitting Diode):** Organic compounds directly light emit karte hain, thinner aur flexible displays, excellent contrast aur colour.
*   **CRT (Cathode Ray Tube):** Aaj kal kam common. Electron beams se phosphors excite karke images banate hain.

**Resolution:** Monitors ki specific resolution hoti hai (horizontal aur vertical pixels ki number). Higher resolution = sharper aur detailed visuals.

**Refresh Rate:** Screen per second kitni baar content update karta hai. Higher refresh rates (60Hz, 120Hz, 240Hz) smoother motion.

**Size:** Compact laptop screens se lekar large widescreen desktop displays tak.

**Properties:**
*   **Color Capabilities:** Various colours display kar sakte hain, kuch full colour gamut support karte hain.
*   **Brightness:** Adjustable brightness levels.
*   **Panel Type:** IPS, TN, VA panels (colour accuracy, viewing angles, response times vary).
*   **Connectivity:** HDMI, DisplayPort, VGA, USB-C ports.

**Examples:**
*   **Computer Monitors:** Desktop computers ke liye (19 to 34 inches+).
*   **Gaming Monitors:** High refresh rates, low response times, adaptive sync.
*   **Professional Monitors:** Graphic designers, photographers, video editors ke liye accurate colour representation.
*   **Television Screens:** Modern TVs similar display technologies use karte hain (larger format).

**Advantages:**
*   **Visual Clarity:** Sharp aur high-resolution visuals.
*   **Real-Time Feedback:** Gaming, video playback, software development ke liye.
*   **Space Efficiency:** Flat-panel monitors space save karte hain (CRT ke muqable).

**Disadvantages:**
*   **Cost:** High-quality monitors with advanced features expensive.
*   **Limited Portability:** Stationary devices.
*   **Power Consumption:** Kuch monitors more power consume karte hain.

### 3.2 Printers & Projectors

Printers aur projectors important output devices hain. Printers digital content ki physical copies produce karte hain, jabki projectors digital content ko larger screen ya surface par display karte hain.

#### Printers

Printers digital documents aur images ko physical paper par reproduce karte hain. Ye inkjet, laser, ya 3D printing technologies use karte hain.

**Printing Technologies:**
*   **Inkjet Printers:** Paper par tiny ink droplets spray karte hain. Text aur colour printing ke liye suitable.
*   **Laser Printers:** Laser beam se photosensitive drum par electrostatic image banate hain. Toner (powdered ink) heat se paper par fuse hota hai. Fast aur high-quality printing.
*   **Dot Matrix Printers:** Aaj kal kam common. Pins ki matrix se inked ribbon par strike karke characters banate hain.
*   **3D Printers:** Three-dimensional objects layer by layer banate hain (plastic filament ya resin se).

**Properties:**
*   **Resolution:** Printed output ki quality determine karti hai. Higher resolution = sharper prints.
*   **Colour Capabilities:** Colour ya monochrome (black and white).
*   **Paper Handling:** Various sizes aur types (letter-sized, envelopes, photo paper, labels).
*   **Speed:** Pages per minute (ppm) ya images per hour.
*   **Connectivity:** Wired (USB, Ethernet) ya wireless (Wi-Fi, Bluetooth).

**Examples:** Epson, HP, Canon inkjet printers; Brother, Dell, Xerox laser printers; MakerBot, Ultimaker 3D printers.

**Advantages:**
*   Tangible aur permanent copy of digital documents.
*   Versatile (text documents se high-quality photographs tak).
*   Modern printers compact aur energy-efficient.

**Disadvantages:**
*   Consumables (ink/toner cartridges) expensive.
*   Inkjet prints water damage ya fading ke susceptible.

#### Projectors

Projectors light sources aur optical systems use karke large, immersive images ya presentations screens/surfaces par project karte hain. Presentations, home theatre setups, aur educational purposes ke liye common.

**Projection Technologies:**
*   **DLP:** Tiny mirrors se light reflect karke image banate hain.
*   **LCD:** Liquid crystal panels se light pass karke image banate hain.
*   **Laser:** Laser light sources use karte hain.

**Properties:**
*   **Resolution:** Projected image ki clarity aur detail determine karti hai.
*   **Brightness:** Lumens mein rated. Higher lumens = well-lit rooms ke liye necessary.
*   **Portability:** Many projectors portable hain.
*   **Projection Size:** Large images produce kar sakte hain.
*   **Connectivity:** Various ports (HDMI, wireless).
*   **Throw Distance:** Screen se kitni door hona chahiye specific image size ke liye.

**Examples:** Multimedia projectors (conference rooms, classrooms, home theatres), short-throw projectors (small rooms), pico projectors (ultra-portable).

**Advantages:**
*   Large aur immersive displays (presentations, education, home entertainment).
*   Versatile applications (business, gaming, movie nights).
*   Modern projectors high-definition resolutions aur connectivity options offer karte hain.

**Disadvantages:**
*   Best image quality ke liye dark ya dimly lit environment required.
*   Advanced features wale projectors expensive.
*   Periodic maintenance (projector lamps replace karna).

### 3.3 Speakers & Audio Output

Speakers aur audio output devices computing aur entertainment systems ke integral components hain jo sound produce karte hain, jisse users music, audio, voice communication, aur other audio content sun sakte hain.

**Working Nature:**
1.  **Sound Reproduction:** Speakers electrical audio signals ko audible sound waves mein convert karte hain. Inme transducers hote hain jo vibrate karke sound produce karte hain.
2.  **Amplification:** Kai audio setups mein amplifiers hote hain jo audio signal ki strength badhate hain (louder aur dynamic sound).
3.  **Stereo and Surround Sound:** Stereo (two-channel) ya surround sound (multi-channel) setups. Stereo mein do speakers (left/right channels). Surround sound mein multiple speakers strategically placed (immersive experience).

**Properties:**
*   **Frequency Response:** Speaker kis frequency range reproduce kar sakta hai (deep bass se high-frequency tak).
*   **Wattage (Power Handling):** Electrical power ki capacity without distortion. Higher wattage = louder sound.
*   **Impedance:** Electrical current flow ka resistance (ohms mein). Amplifier ke output impedance se match hona chahiye.
*   **Sensitivity:** Electrical power ko sound mein convert karne ki efficiency. Higher sensitivity = less power for same volume.

**Examples:**
*   **Computer Speakers:** Desktop/laptop ke liye compact (2.0 ya 2.1 configurations).
*   **Home Theatre Systems:** Multiple speakers for surround sound (front, centre, rear, subwoofer).
*   **Portable Bluetooth Speakers:** Wireless, compact, portable (smartphones, tablets ke saath).
*   **Professional Studio Monitors:** Audio production/recording studios ke liye high-precision speakers.

**Advantages:**
*   **Audio Quality:** Clear, immersive, accurate sound reproduction.
*   **Versatility:** Various sizes/configurations, different environments ke liye adaptable.
*   **Customisation:** Specific audio needs ke hisaab se speakers choose kar sakte hain.

**Disadvantages:**
*   **Cost:** High-quality speakers/audio systems expensive.
*   **Size and Space Requirements:** Larger setups (home theatre) space aur cable management chahte hain.
*   **Power Consumption:** Powerful speakers/amplifiers significant electrical power consume kar sakte hain.

### 3.4 Headsets & Earphones

Headsets aur earphones audio output devices hain jo personal listening experiences ke liye design kiye gaye hain. Ye kaanon par ya andar pehne jate hain aur private, immersive audio content (music, calls, gaming) provide karte hain.

**Working Nature:**
1.  **Sound Delivery:** Miniature speakers (drivers) kaanon ke paas placed hote hain. Ye electrical audio signals ko sound waves mein convert karke ear canal mein direct karte hain.
2.  **Microphone:** Many headsets mein integrated microphone hota hai (two-way communication ke liye) - phone calls, online gaming, video conferencing, voice commands.
3.  **Wired and Wireless:** Wired versions cables se connect hote hain; wireless models Bluetooth ya other technologies use karte hain (greater mobility).

**Properties:**
*   **Form Factor:** Headsets mein headband aur ear cups hote hain. Earphones chhote hote hain aur directly kaanon mein fit hote hain (in-ear, on-ear, over-ear styles).
*   **Noise Isolation:** Passive noise isolation (ear canal physically seal karna) ya active noise-cancelling (ANC) technology (external sounds pick karke cancel karne wali sound waves generate karna).
*   **Sound Quality:** Driver size, audio codecs, frequency response par depend karti hai.
*   **Microphone Quality:** Built-in microphones ke liye crucial (clear voice communication). Noise-cancelling microphones background noise reduce karte hain.

**Examples:**
*   **Over-Ear Headphones:** Large ear cups, comfort aur excellent sound quality (home listening, studio monitoring).
*   **In-Ear Earphones (Earbuds):** Snugly fit in ear canal, highly portable (smartphones, music players).
*   **Gaming Headsets:** Built-in microphones, immersive audio for gaming.
*   **Wireless Earbuds:** Compact, wireless, on-the-go use ke liye.

**Advantages:**
*   **Portability:** Compact aur lightweight, easy to carry.
*   **Privacy:** Private listening experience, others ko disturb nahi karte.
*   **Versatility:** Gaming, phone calls, video conferencing, voice commands ke liye.

**Disadvantages:**
*   **Sound Leakage:** Some earphones/open-back headsets sound leak kar sakte hain (nearby logon ko bother).
*   **Comfort:** Design aur fit ke hisaab se comfort vary karti hai. Extended use mein kuch models uncomfortable ho sakte hain.
*   **Battery Life:** Wireless models ko charging chahiye, battery life long sessions ke liye limitation.

## 📝 4. Summary & Q&A

### Summary
*   **Input Devices:** Users ko data aur instructions computer mein feed karne dete hain.
    *   **Keyboards:** Text typing, commands, shortcuts.
    *   **Pointing Devices (Mouse, Touchpad):** Cursor movement, GUI interaction, selection.
    *   **Scanning Devices:** Physical documents/images ko digital format mein convert.
    *   **OCR:** Printed/handwritten text ko machine-readable text mein convert.
    *   **Biometric Devices:** Unique physical/behavioural traits se authentication (fingerprints, facial recognition).
*   **Output Devices:** Processed information ko users tak present karte hain.
    *   **Monitors:** Visual output (text, images, videos) display karte hain.
    *   **Printers:** Digital documents ki hard copies produce karte hain.
    *   **Projectors:** Digital content ko larger screens/surfaces par display karte hain.
    *   **Speakers:** Sound reproduce karte hain (music, movies, gaming).
    *   **Headsets/Earphones:** Personal, private listening experience.

### Self-Assessment Questions (Quick Answers)
1.  **Which is NOT an input device?** Monitor (Output device hai).
2.  **Primary function of a pointing device?** Data input (cursor control).
3.  **Device for converting handwritten/printed text to digital format?** Scanner (OCR ke saath).
4.  **Biometric input devices use for authentication?** Fingerprint or other unique physical characteristics.
5.  **Primary function of a monitor?** Data display.
6.  **Output device for printed copies?** Printer.
7.  **Headsets and earphones commonly used for?** All of the above (videos, games, music).
8.  **"Resolution" in output devices refers to?** The number of pixels in a digital image.

### Terminal Questions (Hints)
*   **Q: Primary function of a keyboard as an input device?**
    *   *Ans:* Text, numbers, aur commands enter karna. Key press par electrical signal bhejta hai jo computer process karta hai. (Refer Section 2.1)
*   **Q: Working principles of scanning devices?**
    *   *Ans:* Optical sensors (CCD/CIS) se images capture karte hain, resolution (DPI) aur colour depth ke saath digital data mein convert karte hain. (Refer Section 2.3)
*   **Q: Difference between flatbed and sheet-fed scanners?**
    *   *Ans:* Flatbed: Glass bed par document rakhte hain (single pages/books). Sheet-fed: Multiple pages automatically feed hote hain (stacks of paper). (Refer Section 2.3)
*   **Q: Short note on OCR.**
    *   *Ans:* Optical Character Recognition printed/handwritten text ko machine-readable editable text mein convert karta hai. Scanning, preprocessing, character recognition, text extraction steps involve hote hain. (Refer Section 2.4)
*   **Q: Biometric input devices and their role.**
    *   *Ans:* Unique physiological/behavioural traits (fingerprints, face, iris) capture karke identity verify karte hain. High security aur convenience provide karte hain. (Refer Section 2.5)
*   **Q: Main functions of a computer monitor.**
    *   *Ans:* Visual information (text, images, videos) display karna. Display technologies (LCD, LED, OLED, CRT), resolution, refresh rate, size vary karte hain. (Refer Section 3.1)
*   **Q: Key features of headsets and earphones.**
    *   *Ans:* Personal audio output, drivers se sound delivery, microphones (two-way communication), wired/wireless, noise isolation/ANC, various form factors (over-ear, in-ear). (Refer Section 3.4)
*   **Q: Primary function of speakers as audio output devices?**
    *   *Ans:* Electrical audio signals ko audible sound waves mein convert karna. Transducers vibrate karke sound produce karte hain. Amplification, stereo/surround sound configurations. (Refer Section 3.3)
