# 🐙 Git & GitHub — Day 4

> 🚀 Continuing my Git/GitHub Journey  
> 📅 Day 4 — GitHub (Pull Requests, Issues, Fork, Clone & More)

---

## 📌 1. What is GitHub?

👉 GitHub ek **cloud-based platform** hai jaha hum apna code store kar sakte hain  
👉 Ye Git ka **remote version** hai (online repository)

👉 Jaise:
- YouTube → videos store karta hai  
- GitHub → code repositories store karta hai 💻

---

## 📌 2. Git vs GitHub

| Git | GitHub |
|-----|--------|
| Local system pe kaam karta hai | Online platform hai |
| Version control system | Code hosting platform |
| CLI based | UI + CLI dono |

---

## 📌 3. Clone Repository

### ❓ Clone kya hota hai?

👉 Kisi bhi GitHub repository ko **apne local system me copy karna**

```bash
git clone repository_link
```

👉 Isse:
- pura project local machine me aa jata hai
- history bhi aati hai (commits etc.)

---

## 📌 4. Git Pull

### ❓ Pull kya hota hai?

👉 Remote (GitHub) se latest changes ko local system me lana

```bash
git pull
```

👉 Use case:
- GitHub pe update ho gaya
- Terminal me nahi dikh raha
👉 `git pull` → sab sync ho jayega ✅

---

## 📌 5. Branch Rename

👉 Default branch ka naam change kar sakte hain

```bash
git branch -M main
```

👉 Common:
- Git → `master`
- GitHub → `main`

---

## 📌 6. Pull Request (PR)

### ❓ Pull Request kya hota hai?

👉 Jab aap kisi project me change karte ho aur usse main project me add karna chahte ho

---

### 🔥 Process:

1. Branch me kaam karo  
2. Changes push karo GitHub pe  
3. "Pull Request" bhejo  

👉 Project owner decide karega:
- Accept kare (merge) ✅
- Reject kare ❌

---

### 💡 Real Life Use:

👉 Team project me:
- Har koi apni branch pe kaam karta hai  
- Direct main branch me change nahi karta  

---

## 📌 7. Issues

### ❓ Issue kya hota hai?

👉 GitHub ka feature jisme:
- Bugs report karte hain 🐛
- Feature request dete hain 🚀
- Task assign karte hain 👨‍💻

---

### 💡 Example:

👉 "Login button kaam nahi kar raha" → Issue create  
👉 Developer ko assign → wo fix karega

---

## 📌 8. Fork

### ❓ Fork kya hota hai?

👉 Kisi dusre ke repository ki **copy apne GitHub account me banana**

👉 Use case:
- Open-source project me contribute karna

---

### 🔥 Flow:

1. Fork repo  
2. Clone locally  
3. Changes karo  
4. Pull Request bhejo  

---

## 📌 9. GitHub Desktop

👉 GitHub ka GUI tool (no terminal needed)

👉 Isse:
- Commit
- Push
- Pull
- Branch manage

👉 Beginners ke liye easy 👍

---

## 📌 10. Contribution Graph

👉 GitHub profile pe green squares 🟩

👉 Ye show karta hai:
- kitne din commit kiya
- consistency

---

## 📌 11. Basic GitHub Workflow

```text
Local Code → git add → git commit → git push → GitHub
GitHub → git pull → Local update
```

---

## 🧠 Extra Understanding (Important)

👉 GitHub teamwork ke liye bana hai 🤝  
👉 Pull Request → collaboration ka core part hai  
👉 Issues → project management tool bhi hai  

👉 Real world me:
- Fork + PR → open source contribution
- Issues → task tracking

---

## 🚀 Summary

* GitHub → online repo hosting
* Clone → repo download
* Pull → latest changes lana
* Pull Request → changes propose karna
* Issues → bugs / tasks track
* Fork → repo copy apne account me
* GitHub Desktop → GUI tool
