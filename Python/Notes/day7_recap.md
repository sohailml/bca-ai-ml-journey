## 📌 1. Revision — Lists

List ek collection hoti hai jisme multiple values store hoti hain.

```python
my_list = [1, 3, "sohail", 5]
```

👉 List square brackets `[]` me likhi jati hai  
👉 Ye **mutable** hoti hai (change kar sakte hain)  
👉 Kisi bhi type ka data store kar sakte hain  

---

### 🔹 List Methods

```python
list.append(x)      # Last me element add karta hai
list.sort()         # Ascending order me sort karta hai
list.sort(reverse=True)  # Descending order
list.reverse()      # List reverse kar deta hai
list.insert(i, x)   # Specific index par value add karta hai
list.remove(x)      # First occurrence remove karta hai
list.pop(i)         # Index par value remove karta hai
```

---

## 📌 2. Revision — Tuples

Tuple bhi list jaisa hi hota hai, lekin ye **immutable** hota hai.

```python
tup = (1, 2, 3, "sohail")
```

👉 Tuple parentheses `()` me likha jata hai  
👉 Isme change nahi kar sakte  
👉 Indexing aur slicing possible hai  

---

### 🔹 Tuple Methods

```python
tup.index(x)   # Value ka index batata hai (first occurrence)
tup.count(x)   # Value kitni baar aayi hai
```

---

## 📌 3. Revision — Dictionary

Dictionary key-value pairs me data store karti hai.

```python
student = {
    "name": "Sohail",
    "age": 18
}
```

👉 Dictionary `{}` me likhi jati hai  
👉 Ye **mutable** hoti hai  
👉 Keys duplicate nahi hoti  
👉 Ye unordered hoti hai (indexing nahi hoti)  

---

### 🔹 Dictionary Methods

```python
dict.keys()      # Saari keys deta hai
dict.values()    # Saari values deta hai
dict.items()     # Key-value pair tuple me deta hai
dict.get(key)    # Key ke through value deta hai
dict.update(x)   # New value add/update karta hai
```

---

## 📌 4. Revision — Sets

Set unique elements ka collection hota hai.

```python
my_set = {1, 2, 3, 4}
```

👉 Set unordered hota hai  
👉 Duplicate elements allow nahi karta  
👉 Set mutable hota hai, par elements immutable hote hain  

---

### 🔹 Set Methods

```python
set.add(x)           # Element add karta hai
set.remove(x)        # Element remove karta hai
set.pop()            # Random element remove karta hai
set.clear()          # Pura set empty kar deta hai
set.union(set2)      # Do sets ko combine karta hai
set.intersection(s2) # Common elements deta hai
```

👉 Empty set banane ke liye:

```python
empty_set = set()
```
