## 🧠 Concepts Learned Today

### 1. 🔪 String Slicing Beyond Range

If we try something like:

```python
s = "sohail"
print(s[2:100])
```

Even though the string length is smaller (only up to index 5), Python **does NOT throw an error**.

👉 It simply prints whatever is available from index `2` to the end.

**Output:**

```
hail
```

✔️ Python safely handles out-of-range slicing.

---

### 2. 🔍 `.find()` vs `.rfind()`

* `.find()` → Returns the **first occurrence** of a substring
* `.rfind()` → Returns the **last occurrence** of a substring

```python
text = "banana"

print(text.find("a"))   # Output: 1
print(text.rfind("a"))  # Output: 5
```

✔️ `.rfind()` helps when you need the **maximum index** of a value.
