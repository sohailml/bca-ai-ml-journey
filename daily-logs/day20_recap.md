### ⚙️ Practical Learning:

Aaj maine in sab topics ko practically samjha aur commands sikhi:

* `git switch -c ui` → new branch create + switch
* Merge conflict ka concept aur usse manually solve karna
* `git stash` → changes ko temporarily store karna
* `git stash list` → stash list dekhne ke liye
* `git stash pop` → stash wapas lane ke liye
* `git stash apply` → stash ko apply karna bina remove kiye

Git Tags:

* `git tag` → tags dekhne ke liye
* `git tag -a v1.0 -m "commit message"` → annotated tag
* `git tag v2` → simple tag

Rebase:

* `git rebase master` → commits ko rebase karna
* `git rebase --continue` → conflict ke baad continue
* `git rebase --skip` → skip
* `git rebase --abort` → cancel rebase

Extra:

* `git log --oneline -5` → last 5 commits dekhne ke liye
* `touch this.md` → new file create karne ke liye

👉 In commands ka detailed explanation bhi `notes` folder me hai.
