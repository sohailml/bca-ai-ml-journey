🧠 Python Learning — "not in" Operator

Aaj maine Python ke "not in" operator ka use samjha.

"not in" check karta hai ki koi element kisi sequence ya collection ke andar present nahi hai.

Agar element present nahi hota, toh result "True" hota hai. Agar element present hota hai, toh result "False" hota hai.

💻 Example

numbers = [10, 20, 30, 40]

print(20 not in numbers)
print(50 not in numbers)

Output

False
True

💡 Key Learning

- "in" → Check karta hai ki element present hai ya nahi.
- "not in" → Check karta hai ki element present nahi hai ya nahi.

Example: "50 not in numbers" ka result "True" hai, kyunki "50" list ke andar nahi hai.
